# Huneinkids.com
صفحة هبوط «حقيبة عقيدة الطفل المسلم» — ملف واحد `index.html`.

- `index.html`: الصفحة (ضع رابط Apps Script في المتغير `SHEET_URL`).
- `apps_script.gs`: سكريبت تسجيل الطلبات في Google Sheet.
- `vercel.json`: إعدادات Vercel.

Deploy: Vercel → Add New Project → import this repo → Framework: Other → Deploy.
